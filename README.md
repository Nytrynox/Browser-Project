# Browser Project

Custom web browser with integrated AI assistance for intelligent browsing, content summarization, and automated web interactions.

## Features

- Tabbed browsing with session management
- AI-powered content summarization
- Automated form filling and web scraping
- Bookmarks and history management
- Extension support

## Tech Stack

JavaScript, Electron, Node.js, CEF

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/karthik-idikuda/Browser-Project.git
cd Browser-Project
npm install
```

### Usage

```bash
npm start
```
